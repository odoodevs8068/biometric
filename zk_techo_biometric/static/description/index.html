🔗 Dual Integration Support

📌 What It Does

This module seamlessly links your biometric device with Odoo. It captures employee punch-in and punch-out times in real-time, without needing manual data entry. Once set up, everything runs automatically in the background.


🧑‍💼 Features for HR Users

  • Create new employees, depatrtment, Positions, Area Odoo to biometric device.
  • Update employee,depatrtment, Positions, Area details in one click.
  • Delete employee,depatrtment, Positions, Area from the device remotely.
  • Map departments and job positions to the device structure.
  • Print attendance reports by date range with one button.

📋 How It Works

  1. Login to the system securely.
  2. Configure your biometric device (IP + Port).
  3. Click "Check Connection" to confirm it's working.
  4. Click "Live Capture" to start syncing attendance.
  5. Done! The system auto-updates in real-time.
